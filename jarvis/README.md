# 자비스 — 말로 물어보면 대답해 주는 비서 (가입 없이)

컴퓨터를 켜면 알아서 켜져 있고, 마이크에 대고 **"자비스"** 라고 부르면
**"네, 대표님"** 하고 대답한 다음, 질문을 듣고 답을 말로 해 줍니다.

답은 이 PC에 깔린 **클로드 코드(Claude Code)** 가 만들어 줍니다.
부르는 말은 이 PC 안에서 도는 무료 음성인식(**Vosk 한국어 모델**)이 알아듣습니다.
**가입도, 열쇠(키)도, 결제도 필요 없습니다.**

---

## 0. 시작하기 전에

- **되는 컴퓨터**: 윈도우 10 또는 11 (64비트), 인터넷 연결, 마이크와 스피커
- 답이 나오기까지 보통 **5~15초** 걸립니다. (생각하는 시간)
- 설치는 **5분 안팎**, 마우스 클릭 몇 번과 마지막 질문 하나면 끝납니다.
- 처음 한 번 **한국어 음성모델(약 87MB, 풀면 약 250MB)** 을 자동으로 내려받습니다. 1~3분 걸립니다.
- 그다음 첫 질문 때 **받아쓰기 모델(약 500MB)** 을 한 번 더 받습니다. 그때는 5~10분 걸릴 수 있습니다.
- C 드라이브에 **300MB 남짓**의 빈 공간이 있으면 됩니다.

준비물은 하나뿐입니다.

| 준비물 | 확인하는 법 | 돈 |
|---|---|---|
| 클로드 코드 로그인 | cmd 창에서 `claude --version` → 버전이 나오면 OK | 기존 구독 |

> 가입·키·.ppn 파일·AccessKey 같은 것은 **하나도 필요 없습니다.**
> 예전(1.0) 판에서 쓰던 Picovoice는 이제 쓰지 않습니다.

## 1. 설치 (3단계)

### 1단계 — 압축 풀기

받은 `davis-voice-jarvis.zip` 압축을 풉니다.

- **권장 위치**: `C:\davis` 처럼 짧고 단순한 곳
- 바탕화면이나 한글 폴더 이름도 대부분 됩니다.
- **OneDrive로 동기화되는 폴더는 피하세요.** 파일이 잠기면서 오류가 날 수 있습니다.
- 압축을 푼 폴더 안에 `install.bat` 이 보이면 성공입니다.
- **예전 '다비스' 판을 쓰셨다면**: 그 폴더를 이미 지우셨다면 그대로 새 폴더에 풀고
  `install.bat` 만 실행하시면 됩니다. 폴더가 아직 남아 있다면 새 설치가 잘 되는 것을
  확인한 뒤 지우세요. 부팅 자동 시작은 설치할 때 **이 폴더 기준으로 다시 등록되고,
  예전 '다비스 시작' 항목은 자동으로 정리됩니다.**

### 2단계 — install.bat 실행

`install.bat` 을 **더블클릭**합니다.

- 파란 창이 뜨면서 "Windows의 PC 보호" 경고가 나오면
  **추가 정보 → 실행** 을 누르세요. (직접 만든 파일이라 나오는 안내입니다.)
- 검은 창이 열리고 혼자 설치를 시작합니다. **3~7분** 걸립니다.
- 창에 글자가 막 지나가도 정상입니다. 끄지 말고 기다려 주세요.
- 물어보는 것은 마지막 **"지금 자비스를 시작할까요?"** 한 번뿐입니다.

### 3단계 — 마지막 질문에 `Y`

**"지금 자비스를 시작할까요?"** 가 나오면 `Y` 를 입력하고 Enter.
3초쯤 뒤 마이크에 대고 **"자비스"** 라고 말해 보세요.

> 설치 중 "클로드 코드를 찾지 못했습니다" 라는 안내가 나오면 3장을 보세요.
> 자비스는 답을 클로드 코드로 만들기 때문에, 그것만 있으면 됩니다.

## 2. 부르는 말

부르는 말은 **"자비스"** 입니다. 길게 **"헤이 자비스"** 라고 해도 됩니다.

- 마이크에 대고 부르면 **삐** 소리와 함께 **"네, 대표님"** 이라고 대답합니다.
- 대답한 뒤 **8초** 안에 질문하세요.
- 부르면서 바로 이어 말해도 됩니다. 예: **"자비스, 오늘 날씨 어때?"**
  → "네, 대표님" 대답과 함께 그 질문을 그대로 알아듣습니다.
- 말이 끝나고 1.2초쯤 조용하면 자동으로 질문이 끝납니다.

### 잘 안 알아들을 때 (한 번만 해 두면 됩니다)

짧은 한 단어라서, 마이크가 멀거나 주변이 시끄러우면 흔들릴 수 있습니다.

1. **인식 테스트**로 먼저 확인해 보세요. 검은 창(터미널)에서:

   ```
   .venv\Scripts\python davis.py --test-wake
   ```

   20초 동안 마이크로 듣고, 무엇이 들리는지 / 부르는 말을 알아들었는지 한국어로 보여 줍니다.
2. 잘 안 되면 **"헤이 자비스"** 처럼 길게 불러 보세요. 훨씬 잘 알아듣습니다.
3. 그래도 안 되면 `config.json` 의 `wake_sensitivity` 를 **0.6~0.8** 로 올려 보세요.
   (기본 0.4는 주변 대화에 덜 반응하도록 낮춰 둔 값입니다. 헛반응이 늘면 0.3으로 내립니다.)
4. 마이크는 **책상 위, 입에서 50cm 안쪽**이 가장 잘 됩니다.

## 3. 클로드 코드 로그인 확인

자비스는 답을 **클로드 코드**로 만듭니다. 이미 깔려 있고 로그인돼 있으면 그대로 쓰시면 됩니다.

확인하는 법:

1. 윈도우 키를 누르고 `cmd` 를 쳐서 **명령 프롬프트**를 엽니다.
2. `claude --version` 을 치고 Enter → 버전이 나오면 설치된 것입니다.
3. `claude` 를 치고 Enter → 대화 화면이 뜨면 `/login` 을 입력해 로그인합니다.
   (구글 계정으로 로그인할 수 있습니다.) 끝나면 `/exit` 로 나옵니다.

설치되어 있지 않다면:

1. **nodejs.org** 에서 **LTS** 버전을 받아 설치합니다.
2. 명령 프롬프트를 **새로 열고** `npm install -g @anthropic-ai/claude-code` 를 칩니다.
3. `claude` 를 실행해 로그인합니다.

## 4. 쓰는 법

평소에는 아무것도 하지 않으셔도 됩니다. 컴퓨터를 켜면 자비스가 조용히 켜집니다.

1. 마이크에 대고 **"자비스"** 라고 부릅니다.
2. **삐** 소리와 함께 **"네, 대표님"** 이라고 대답합니다.
3. 이어서 질문하세요. (또는 부르면서 바로 질문해도 됩니다.)
4. 답을 만들어 음성으로 들려줍니다.

질문 예시:

- "오늘 날씨 어때?"
- "이번 주 금요일이 며칠이야?"
- "다음 주 화요일 오후 일정 정리해 줘"
- "네이버플레이스 상위노출 영업할 때 첫 마디 뭐라고 하면 좋을까?"
- "파이썬으로 폴더 안 파일 목록 뽑는 방법 알려줘"

답이 너무 길면 400자에서 문장 단위로 잘라 읽습니다.

## 5. 끄기 · 다시 켜기 · 자동 시작

**끄기**
작업 표시줄에서 우클릭 → **작업 관리자** → `pythonw.exe` 를 찾아 **작업 끝내기**.

**다시 켜기**
이 폴더의 **`자비스 시작.vbs`** 를 더블클릭합니다. (창은 뜨지 않습니다.)

**자동 시작 끄기**
윈도우 키 + R → `shell:startup` 입력 → 열린 폴더에서 **자비스 시작** 바로가기를 지웁니다.
(예전 판의 **다비스 시작** 바로가기가 함께 보이면 그것도 지웁니다.)

**자동 시작 다시 켜기**
`install.bat` 을 다시 실행하면 됩니다. (설정과 프로그램은 그대로 두고 바로가기만 다시 만듭니다.
이때 예전 '다비스 시작' 항목도 함께 정리합니다.)
또는 이 폴더의 `자비스 시작.vbs` 를 `cscript "자비스 시작.vbs" /install` 로 실행해도 됩니다.

**로그를 보면서 실행 (문제 확인용)**
이 폴더에서 Shift + 우클릭 → **터미널(또는 PowerShell) 여기서 열기** →

```
.venv\Scripts\python davis.py --console
```

끝낼 때는 창에서 **Ctrl + C** 를 누릅니다.

**상태 점검**

```
.venv\Scripts\python davis.py --check
```

설정·음성모델·패키지·마이크·클로드 코드가 모두 준비됐는지 한국어로 알려 줍니다.

**부르는 말 인식 테스트 (20초)**

```
.venv\Scripts\python davis.py --test-wake
```

**스피커 테스트**

```
.venv\Scripts\python davis.py --test-voice
```

## 6. 설정 바꾸기 (config.json)

이 폴더의 `config.json` 을 **메모장**으로 열어 고치고 저장하면 다음에 부를 때 적용됩니다.
(쉼표와 따옴표를 지우면 파일이 깨집니다. 값만 바꾸세요.)

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `vosk_model_path` | 한국어 음성모델 폴더. 비워 두면 프로그램 폴더에서 찾습니다 | (빈칸) |
| `wake_words` | 부르는 말 목록 | `["자비스", "헤이 자비스"]` |
| `wake_sensitivity` | 부르는 말 민감도. 0.3이면 또박또박 부를 때만, 0.85면 흐린 발음까지 받아 줌 (0.3~1.0) | 0.4 |
| `wake_reply` | 깨울 때 하는 말 | "네, 대표님" |
| `whisper_model` | 받아쓰기 모델. `small` 권장, 컴퓨터가 느리면 `base` | small |
| `tts_voice` | 목소리. 남자 목소리는 `ko-KR-InJoonNeural` | ko-KR-SunHiNeural |
| `max_answer_chars` | 답변 최대 글자 수 | 400 |
| `claude_exe` | 클로드 실행 파일. PATH에 없으면 전체 경로 | claude |
| `claude_timeout_sec` | 클로드가 답할 때까지 기다리는 시간(초) | 180 |
| `claude_cwd` | 클로드가 일할 폴더(비우면 사용자 폴더) | (빈칸) |
| `silence_sec` | 말이 끝났다고 볼 무음 시간(초) | 1.2 |
| `max_record_sec` | 질문 최대 녹음 시간(초) | 10 |
| `min_record_sec` | 질문 최소 녹음 시간(초) | 1 |
| `listen_wait_sec` | 부른 뒤 기다려 주는 시간(초) | 8 |
| `speech_threshold` | 말소리로 볼 최소 크기. 시끄러우면 0.03~0.05 | 0.02 |
| `owner_name` | 자비스가 부르는 사람 이름 | "김용진" |
| `assistant_name` | 비서 이름 | "자비스" |
| `announce_start` | 켤 때 "준비됐어요"라고 말할지 | false |

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| 아무 반응이 없어요 | 작업 관리자에 `pythonw.exe` 가 있는지 확인. 없으면 `자비스 시작.vbs` 실행. 그래도 안 되면 `--console` 로 실행해 빨간 글씨 확인 |
| "자비스"라고 불러도 반응이 없어요 | `--test-wake` 로 확인 → "헤이 자비스"로 길게 불러 보기 → `wake_sensitivity` 0.6~0.8 → 마이크를 입 가까이 |
| 부르지 않았는데 반응해요 | `wake_sensitivity` 를 0.3으로 낮추기. '자비스'와 소리가 비슷한 말(자비, 비스킷, 서비스)에 가끔 반응할 수 있습니다. TV·라디오가 가까이 있으면 마이크를 옮기기 |
| "마이크를 찾지 못했어요" | 마이크가 꽂혀 있는지 확인. 윈도우 설정 → 시스템 → 소리 → 입력에서 마이크가 잡히는지 확인 |
| 부르면 반응은 하는데 질문을 못 알아들어요 | 조용한 곳에서 또박또박. `speech_threshold` 를 0.03으로 올려 보세요 |
| "클로드 코드가 설치되지 않았어요" | 3장대로 클로드 코드를 설치 |
| "로그인이 풀린 것 같아요" | cmd 창에서 `claude` 실행 → `/login` |
| 답이 안 들려요 | `--test-voice` 로 확인. 스피커·볼륨 확인. 그래도 안 되면 인터넷 연결 확인 |
| 첫 질문이 아주 느려요 | 처음 한 번은 모델을 내려받는 중입니다. 5~10분 기다려 주세요 |
| 검은 창이 자꾸 떠요 | `install.bat` 이 만든 시작프로그램 바로가기를 쓰세요. `davis.py` 를 직접 열면 창이 뜹니다 |
| 백신이 막아요 | `install.bat`, `자비스 시작.vbs` 를 예외로 등록 |
| 노트북을 덮으면 반응이 없어요 | 절전 모드에서 마이크가 꺼집니다. 전원 설정에서 절전을 끄거나 덮개 설정을 바꾸세요 |
| 설치 중 음성모델을 못 받았어요 | 인터넷 확인 후 `install.bat` 다시 실행, 또는 `--setup` 실행. 아래 10장 참고 |

**로그 보기**: 이 폴더의 `davis.log` (프로그램 폴더에 못 쓰면 `%LOCALAPPDATA%\davis-voice\davis.log`).
질문 내용은 기록하지 않고, 길이·처리시간·오류만 남깁니다.

## 9. 개인정보에 대해

- **"자비스"라는 말을 듣는 일은 이 PC 안에서** 처리됩니다. 소리를 밖으로 보내지 않습니다.
- **질문 받아쓰기도 이 PC 안에서** 처리됩니다. (Whisper 또는 Vosk 모델, 최초 1회만 내려받음)
- **다만 질문 내용은 답을 만들기 위해 클로드(Anthropic)로 전송됩니다.**
- **답변 음성은 마이크로소프트의 음성 서비스로 만들어집니다.** 즉 답변 문장은 마이크로소프트로 전송됩니다.
- **녹음 파일은 저장하지 않습니다.** 메모리에만 있다가 사라집니다.
- 로그에는 질문 내용이 남지 않습니다.
- 이런 점이 불편하시면 `--console` 로 실행해 어떤 질문이 오가는지 직접 확인하실 수 있습니다.

## 10. 음성모델을 직접 받아야 할 때

인터넷이 막혔거나 자동 다운로드가 계속 실패하면, 다른 곳에서 받아 폴더째로 넣으면 됩니다.

1. 브라우저에서 아래 주소를 엽니다. (약 87MB)
   `https://alphacephei.com/vosk/models/vosk-model-small-ko-0.22.zip`
2. 압축을 풀면 **`vosk-model-small-ko-0.22`** 폴더가 나옵니다.
3. 그 폴더를 **자비스 폴더(`C:\davis`) 안에** 그대로 넣습니다.
   (폴더 안에 `am`, `conf`, `graph` 폴더가 보이면 성공입니다.)
4. `install.bat` 을 다시 실행하거나, 아래처럼 상태를 확인합니다.

```
.venv\Scripts\python davis.py --check
```

폴더를 다른 곳(예: `D:\models`)에 두었다면 위치를 알려 주면 됩니다.

```
.venv\Scripts\python davis.py --setup --model-path "D:\models\vosk-model-small-ko-0.22"
```

## 11. 예전 '다비스' 판에서 넘어올 때

1. 새 압축을 새 폴더(예: `C:\davis-jarvis`)에 풉니다.
2. `install.bat` 을 실행합니다. 시작프로그램에 **자비스 시작** 바로가기를 새로 만들고,
   예전 **다비스 시작** 바로가기는 지웁니다.
3. 마이크에 대고 "자비스"라고 불러 잘 되는지 확인합니다.
4. 확인이 끝나면 예전 폴더(`C:\davis` 등)를 지웁니다. 이미 지우셨다면 이 단계는 필요 없습니다.

> 예전 폴더를 지우지 않고 두면 프로그램은 두 개가 되지만, 부팅 때 켜지는 것은
> 새 폴더의 자비스 하나뿐입니다.

## 12. 완전히 지우기

1. 윈도우 키 + R → `shell:startup` → **자비스 시작** 바로가기 삭제
2. 작업 관리자에서 `pythonw.exe` 작업 끝내기
3. 이 폴더(`C:\davis` 등)를 통째로 삭제 (음성모델 250MB도 함께 지워집니다)
4. (선택) `%LOCALAPPDATA%\davis-voice` 폴더 삭제 — 캐시와 로그가 들어 있습니다
